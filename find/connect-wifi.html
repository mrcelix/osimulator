Where is “Connect to Wi‑Fi” on every operating system?

Join a wireless network on any phone, tablet or computer. Here is exactly where to find it on each system.

Open the interactive finder →
Operating systemWhere to find it
iOSOpen Settings → Wi‑Fi → Turn Wi‑Fi on → Tap a network and type the password → Tap Join
AndroidSettings → Network & internet → Internet → Turn Wi‑Fi on → Tap the network name → Enter the password and tap Connect
macOSSystem Settings → Wi‑Fi → Turn Wi‑Fi on → Choose a network from the list → Enter the password to authenticate
WindowsSettings → Network & internet → Wi‑Fi → Turn Wi‑Fi on → Show available networks and pick one → Enter the network key and Connect
