Opening the Windows 98 Control Panel one applet at a time

Every setting on a nineteen-nineties desktop lived inside a small window with tabs along the top, and the whole system amounted to eighty-eight rows. That is fewer choices than a modern phone offers for notifications alone. Working through the applets again is a quick lesson in how much of what a computer now decides for you was once yours to configure.

How Windows 98 organises Settings

There is no hierarchy at all. Display, Network, System, Add/Remove Programs, Sounds, Mouse, Regional Settings, Date/Time, Passwords, Multimedia and Modems sit as equals in a single folder of icons, and each one opens a dialog with its own tabs. Nothing groups them; alphabetical order is the only organising idea. That flatness means you have to know what an applet is called before you can use it, which is why so much period documentation begins by naming the icon. It also means nothing is ever more than two clicks away.

The depth lives inside the dialogs rather than in the list. Display alone carries Background, Screen Saver, Appearance, Effects and Settings as tabs, with Wallpaper, Pattern, Colors and Screen area beneath them. System splits into General, Device Manager, Hardware Profiles and Performance, and Device Manager was where most troubleshooting ended up. Network exposes Client for Microsoft Networks, Dial-Up Adapter and TCP/IP directly, so configuring a connection meant understanding protocol names. Compared with anything modern, the vocabulary is unapologetically technical and the safety rails are missing.

Three settings worth finding

  • Settings > System > Device Manager

    Every hardware problem of the era ended here, in a tree of components with warning marks beside the ones that had failed. It sits under System alongside General, Hardware Profiles and Performance, and it is the single page most period support instructions ask you to open.

  • Settings > Display > Screen Saver

    Screen savers existed to protect phosphor displays from burn-in and became a form of decoration instead. The tab sits beside Background, Appearance, Effects and Settings, and it is worth opening as a reminder that display configuration used to mean choosing patterns and colours by hand.

  • Settings > Add/Remove Programs > Windows Setup

    Optional parts of the operating system were installed and removed here rather than downloaded, which is a genuinely different model. The same applet holds Install/Uninstall and Startup Disk, so adding a component, removing an application and making rescue media all shared one window.

How this menu got here

The Control Panel folder arrived with the earliest graphical releases and barely changed shape through the nineteen-nineties; new hardware simply added another icon. Windows 95 established the tabbed dialog style, and Windows 98 Second Edition added applets for the hardware of its day while leaving the arrangement alone. The two builds in the simulator, 98 SE and 95, are close relatives rather than a redesign, so comparing them is mostly a matter of spotting additions. The layout is reconstructed from the shipping interface.

Who this is useful for

Anyone restoring old hardware or running a period machine for music, games or industrial control needs the applet names right. Teachers illustrating how interface conventions developed can show the tabbed dialog in its original form. Writers and set designers working on anything set in the nineteen-nineties get an accurate reference. People who simply want to see a computer they grew up with can look without finding a working machine.

What is real and what is sample data

The structure is the real thing: menu names, their order, how they are grouped and what sits inside each one. That is why this article can quote a path such as Settings > System > Device Manager and expect it to match your classic PC.

The state cannot be. A device name, an address, a build number, a network name, a storage figure, whether a particular switch is on or off — those belong to a physical classic PC, not to a menu tree. The simulator fills those in with obvious sample values. Use them to learn where a figure lives; look at your own classic PC to learn what it says.

Questions about Windows 98 settings

Is this Windows 98 or Windows 95?

Both are available and you can switch between them. The two releases share almost all of the Control Panel layout, so the differences are additions rather than rearrangements. Choosing 98 SE gives the later set of applets, while 95 shows the arrangement as it stood when the tabbed dialog style was still new.

Does anything here actually run Windows 98?

No. This is a reproduction of the settings interface, not an emulator running the operating system, and nothing executes period software. It is useful for finding where an option lived and what it was called. Any figure shown inside a dialog, such as memory or a registered name, is a sample value.

Why does the Control Panel have no categories?

Grouping came later. In this era each applet was a separate small program dropped into one folder, so the list grew as hardware makers added their own. Category headings only appeared once the number of icons became unmanageable, which is a change you can see by comparing this system with a later release.
