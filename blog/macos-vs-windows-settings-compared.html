macOS System Settings vs the Windows Settings app

Apple and Microsoft have converged on the same idea: a sidebar of categories with a search box on top. What separates them now is how much of the old control surface each one still drags along.

Two sidebars that look alike

macOS Ventura replaced the old System Preferences grid with System Settings in 2022, a scrolling sidebar that borrows heavily from the iPhone. Windows 11 arrived a year earlier with a similar shape: a fixed category list on the left, detail pane on the right.

The category names are close enough to be confusing. Windows uses System, Bluetooth & devices, Network & internet, Personalisation, Apps, Accounts, Time & language, Gaming, Accessibility, Privacy & security and Windows Update.

macOS instead leads with the connectivity items, Wi-Fi and Bluetooth and Network, then Notifications, Sound and Focus, then General, Appearance, Accessibility and the hardware panes. A side-by-side view is on the macOS vs Windows comparison page.

The Control Panel problem

This is the single biggest structural difference. Windows 11 still ships the Control Panel from the 1990s alongside the modern Settings app, and a handful of dialogs still open it, including several older device and administrative applets.

Microsoft has migrated most everyday options into Settings, but the seam is visible: some links quietly hand you off to a window with a different design language. Anyone who remembers Windows 7 will recognise those panels immediately.

macOS has no equivalent second system. There are advanced sheets hidden behind Details or Options buttons, and a few things live in Disk Utility or Terminal instead, but there is only one Settings app to search.

How search behaves on each

Both put a search field at the top of the sidebar, and on both it is faster than hunting for the right category.

Windows search is broader in scope: typing into the Settings box, or into the Start menu, returns matches from Settings and from Control Panel applets together, which is genuinely useful given the split.

macOS search filters the sidebar and highlights the exact row inside a pane once you open it. It matches on feature names rather than plain-English phrasing, so searching for a described symptom works less often than searching for the actual label.

Where the common settings live

Four areas cover most of what people actually look for.

  • Display: Windows puts it under System, then Display. macOS gives Displays its own top-level pane.
  • Network: Windows groups everything under Network & internet. macOS separates Wi-Fi from the wider Network pane, as covered in the Wi-Fi guide.
  • Privacy: both use a per-app permission list, under Privacy & security on Windows and Privacy & Security on macOS.
  • Updates: Windows Update is a top-level item; macOS files Software Update inside General.

Appearance is another split, with Windows keeping light and dark themes under Personalisation and macOS placing them in Appearance. The dark mode guide covers both routes.

Which is easier to live with

macOS is more consistent, because there is exactly one place to look and Apple rarely leaves an old interface running beside a new one.

Windows is more discoverable, largely because its search reaches further and its category names read more like plain descriptions of tasks. The cost is the occasional jump into a legacy dialog with different conventions.

Key points

  • Both now use a sidebar of categories with search on top.
  • Windows still carries the legacy Control Panel; macOS has no equivalent.
  • Updates are top-level on Windows but nested under General on macOS.

Frequently asked questions

Does Windows 11 still need the Control Panel?

For most everyday tasks, no. A few legacy and administrative dialogs still open Control Panel windows, so it has not been removed, but the modern Settings app now covers the common cases.

What replaced System Preferences on a Mac?

System Settings, introduced in macOS Ventura in 2022. It contains the same controls reorganised into an iPhone-style sidebar, so older tutorials referring to System Preferences panes still broadly apply.

Where is software update on each system?

Windows has a top-level Windows Update entry in Settings. macOS files Software Update inside the General pane in Ventura and later, and at the top level in older versions.
