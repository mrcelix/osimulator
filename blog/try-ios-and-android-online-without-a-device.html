Try iOS and Android online, without owning either device

You can open the settings menus of iOS, Android and more than forty other systems in a browser tab, with nothing to install. Knowing precisely where the reproduction stops is what makes it useful rather than misleading.

What you get in a browser tab

Wanting to see how the other platform works is a common reason to borrow somebody's phone. A settings simulator answers the same question in a tab: you open iOS, iPadOS, Android, Windows, macOS, Ubuntu, ChromeOS or any of more than forty systems and move through the menus the way you would on the hardware.

There is no download, no account and no virtual machine waiting to boot. Because it runs in the page rather than streaming a device, it also works on managed or locked-down computers where installing software is not permitted.

That makes it a practical way to settle an argument about which platform buries a feature deeper, to prepare for a switch, or to follow instructions written for a device you do not have in front of you.

What is reproduced faithfully

The simulator reproduces menu structure: the sections, the order they appear in, the sub-pages behind each row and the wording of the labels. For Android, Ubuntu, ChromeOS, webOS OSE and Firefox OS that structure is machine-extracted verbatim from the systems' open-source code rather than retyped from screenshots, so the labels match the source.

It also spans 87 version combinations, which matters because sections move between releases. Opening two versions of the same system side by side shows what was renamed, and the version change log lists those differences in writing.

What it cannot show you

Be equally clear about the other half. A simulator cannot show live device state, and it does not claim to. The sample values on screen, including device names, IP addresses, serial and build numbers, storage figures and the position of individual switches, are illustrative placeholders rather than readings taken from a real machine.

So never quote a build number or a network address from the simulator as fact, and do not expect a toggle to reflect how any particular phone is configured. The data provenance page states item by item which parts come verbatim from source and which are sample data.

Answering support questions with it

Inside that boundary it handles a large share of everyday questions, because most of them are about navigation rather than state. Where does the eSIM section sit on this Android version. Which screen holds the update button. What is this option called now that it has been renamed.

Walk the path once, then send the person a written version. Pairing the walk with a guide keeps the wording consistent: the eSIM guide and the screenshot guide both name sections rather than assuming one layout, and the settings finder maps a feature name to its path.

Where to start

If you are considering a switch, open the system you do not own and read its first three sections. Those hold the settings you touch weekly, and the differences in naming show up immediately. Battery, storage and notification controls are the usual sticking points, and seeing them once removes most of the friction of moving across.

iOS compared with Android is a useful companion for the mobile pair, and the iOS hub lists which releases you can open. Then load the osimulator settings simulator and pick a system you have never used at all.

Key points

  • Menu structure is faithful; several systems are verbatim from source
  • Sample values are illustrative, never live device state
  • Best for navigation questions, not for reading a device's settings

Frequently asked questions

Is this a real iPhone running in the browser?

No. It is a faithful reproduction of the settings menus, not an emulated device, so apps do not run and nothing on screen reflects real hardware.

Are the values shown in the menus real?

No. Device names, IP addresses, build numbers and switch positions are illustrative sample values, as the data provenance page explains in detail.

Do I need an account or a download?

Neither. It opens in a browser tab, runs offline once loaded, and asks for no sign-in.
